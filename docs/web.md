# 网页端交互约定

桌面、手机浏览器和 Tauri 外壳用的是同一份网页。改动某种输入方式或布局时，需要保留其他设备的操作路径；Tauri 外壳与网页的约定见[客户端文档](clients.md)。

## 书库与阅读状态

- 书库卡片和最近阅读用相同的入口：点封面接着读，点标题打开详情抽屉。抽屉、阅读器详情面板和阅读设置用浅层路由加入历史记录，返回手势先关面板，不离开书库或阅读器。
- 书库在电脑上占窗口宽度的 90%，居中、不设最大宽度；网格卡片最小 200px。列表在桌面排成表格，手机上同一条记录排成三行。上下都有页码；每页 50、100 或 200 本，默认 100，更改后回到第一页。排序和每页本数记在设备上，但链接要带排序，只有地址里没有时才用设备偏好。
- 筛选行显示新书、用户分类和收藏的标签，不用全库热门标签替代。收藏标签跨设备共享，多选时精确匹配并取交集。静态分类 Favorites 或“收藏”用书签按钮快捷切换；LRR 的 DuplicateArchives 放在控制台问题页。旧链接里的阅读状态筛选仍然有效。
- “新书”指带新书标记且还没有进度。开始阅读只写进度，不清标记，以免触发全库快照重建。“读完”表示曾到达最后一页，重读前页不清除。手动标记时保留已有页码；没有进度才记为最后一页。单本和批量都能取消标记。网页先显示本次操作的结果，不等下一次搜索快照。

## 阅读器

- 整页模式会把小图放大到占满可用空间。适应宽度时，滚轮、空格或 PageDown 先滚完当前屏再翻页。一次滚轮动作最多翻一页，包括触控板惯性；可在阅读设置关闭滚轮翻页。手机和平板的单指滑动可翻页，两指缩放或已放大时不翻。
- 桌面整页模式支持 Ctrl 加滚轮或键盘缩放，最高 8 倍。放大后可以平移，点两侧不翻页，翻页后复位。旋转时工具栏随页面一起转。全屏时收起工具栏、背景全黑；不支持网页全屏的 iPhone Safari 只收起工具栏。
- 电脑默认取原图，避免整页缩小后再放大时模糊。触屏设备按显示宽度和像素比取 1440 或 2160 档，放大该页后换原图，也可设为总用原图。大图解码前用缩略图垫底，放大换原图时保留已显示的缩小图。
- 翻页模式等当前屏加载完，依次预取下一屏、下两屏和上一屏，翻走时取消。下一屏下载后顺便解码，不阻塞下一张下载；超过 1200 万像素的原图不预解码。
- 条漫按页面高宽比的中位数判断（至少 2），可在控制台关闭自动判断，或在阅读器按本覆盖。条漫连续纵向滚动，横屏默认居中、宽 800px，可调到 480–1200px，竖屏占满宽度。空格或 PageDown 滚一屏并留少量重叠，工具栏箭头按图片跳转。
- 详情面板的操作和推荐固定，只有页面缩略图区域单独滚动，打开时定位到当前页。窄于 600px 时分成“页面、信息、相似”三页。工具栏和面板的首末页按钮方向一致。

## 设置、主题与离线缓存

- 新增控制台设置时，复用 `web/src/routes/admin/settings/` 的 `Setting`、`Check` 和 `CardHead`。说明放进 `help`，按需在该行展开。设备偏好留在浏览器，共用的书库设置写服务端。
- 配色集中在 `web/src/lib/themes.ts`。组件用主题变量，填色按钮的文字用 `--on-accent`；启动时先套用保存的主题，避免首屏闪色。动画仅限面板滑入和相邻两屏翻页，统一走 `motion.ts` 并尊重减少动态效果设置。跳页、条漫和连续滚动不用翻页动画。
- 局域网 HTTP 没有 Service Worker，图片必须能单靠 HTTP 缓存正确复用。HTTPS 下新增接口时，在 `web/src/service-worker/routes.ts` 决定是否离线缓存。控制台、登录、下载、MCP 和写接口不缓存；退出登录或收到 401 时清理接口和图片缓存。缓存策略和离线时的限制见[装到主屏幕和离线阅读](server.md#装到主屏幕和离线阅读)。
